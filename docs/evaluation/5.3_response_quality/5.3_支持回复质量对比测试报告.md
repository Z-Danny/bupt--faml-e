# 5.3 支持回复质量对比测试

## 5.3.1 测试目的

本节旨在比较普通大模型直接回复与 FamleeAI Agent 框架回复在大学生日常情绪支持场景中的差异。测试目的不是证明 FamleeAI 具备心理治疗能力，而是验证其在非临床心理支持语境下，是否能够表现出更清晰的回复结构、更明确的情绪识别过程、更合适的支持策略选择，以及更适合后续记录与反思的输出材料。

具体关注以下问题：

1. 普通大模型是否容易生成泛化安慰；
2. FamleeAI 是否能够先识别情绪，再选择合适的支持策略 Skill；
3. FamleeAI 回复是否更贴合用户当前情绪；
4. FamleeAI 回复是否更非评判、更鼓励用户继续表达；
5. FamleeAI 是否能够生成可进入情绪日历、趋势画像和阶段总结的记录摘要。

## 5.3.2 测试材料与方法

本测试构建 20 条大学生日常情绪表达场景，覆盖焦虑、难过、生气/烦躁、平静和开心五类情绪。每条测试材料包括编号、预期情绪、场景类型和用户输入。用户输入长度控制在约 30-80 字，尽量贴近日常校园表达方式。

测试比较两个系统：

1. **普通大模型直接回复**：输入用户表达后，直接生成一段心理支持回复，不显式加入情绪识别、Skill 路由和记录摘要。
2. **FamleeAI Agent 框架回复**：输入用户表达后，先经过情绪识别 Skill、安全保护 Skill、隐私保护 Skill 和策略路由机制，再由对应心理支持策略 Skill 生成回复，并生成记录摘要。

测试流程如下：

```text
用户输入
-> 普通大模型直接回复

用户输入
-> 情绪识别 Skill
-> 安全保护 Skill
-> 隐私保护 Skill
-> 推荐支持策略 Skill
-> FamleeAI 回复
-> 记录摘要
```

## 5.3.4 评价维度

本测试采用 3 位评审者盲评方式。每条用户输入下放置两个系统回复，随机标记为 A/B，不向评审者说明其来源。评审者从以下五个维度对每条回复进行 1-5 分评分。

| 维度 | 说明 |
|---|---|
| 情绪贴合度 | 回复是否准确回应用户当前情绪 |
| 策略匹配性 | 是否采用合适支持方式，如共情、认知梳理、轻量缓冲 |
| 非评判性 | 是否避免说教、诊断、命令式建议 |
| 继续倾诉意愿 | 回复是否让用户愿意继续表达 |
| 记录与反思价值 | 回复内容是否能沉淀为后续情绪记录或反思材料 |

盲评材料见 `5.3_专家盲评表.xlsx`。该表仅包含 A/B 回复内容和评分栏，不暴露系统来源。A/B 与真实系统的对应关系单独保存在 `5.3_AB盲评材料表.xlsx`，仅用于研究者汇总统计，不应发给评审者。

## 5.3.5 测试结果

评分统计表见 `5.3_评分统计表.xlsx`。目前已完成两组系统回复的实际生成，并使用豆包模型进行自动盲评评分。该评分模拟 3 类评审视角：心理/学生工作视角、交互设计/HCI 视角、AI/数字媒体视角。需要注意的是，该结果属于 AI 自动评分，不等同于真实人工专家评分；若用于正式论文，应在方法部分说明评分来源，或再补充人工评审。

**表 5-4 支持回复质量评分结果**

| 系统 | 情绪贴合度 | 策略匹配性 | 非评判性 | 继续倾诉意愿 | 记录与反思价值 |
|---|---:|---:|---:|---:|---:|
| 普通大模型 | 4.58 | 4.18 | 4.97 | 4.07 | 3.57 |
| FamleeAI | 5.00 | 5.00 | 5.00 | 4.88 | 4.73 |

从自动评分结果看，FamleeAI 在五个维度上均高于普通大模型。其中提升最明显的是“记录与反思价值”（+1.17）、“策略匹配性”（+0.82）和“继续倾诉意愿”（+0.82）。这说明普通大模型虽然能够生成自然、非评判的安慰性回复，但在显式支持策略、后续反思材料和交互延展性方面相对不足。

## 5.3.6 结果分析写作要点

本轮自动评分显示 FamleeAI 在情绪贴合度、策略匹配性和记录与反思价值上高于普通大模型，可以从以下角度解释：

1. **情绪识别前置**：FamleeAI 在生成回复前先识别用户表达中的主要情绪和风险线索，因此回复更容易围绕当前情绪展开，而不是直接进入泛化安慰。
2. **支持策略显式路由**：FamleeAI 根据情绪状态、用户选择的人格和工具触发情况选择对应 Skill，例如焦虑场景更容易进入认知梳理，难过场景更容易进入共情承接。
3. **非评判性约束**：FamleeAI 的基础安全提示要求避免诊断、说教和命令式建议，因此回复语气更适合继续倾诉。
4. **记录摘要生成**：FamleeAI 在回复过程中生成情绪标签、支持需求和记录摘要，可进入情绪日历、趋势画像和阶段总结，形成长期反思闭环。

|---|---|---|

## 5.3.8 小结

普通大模型能够生成自然的安慰性回复，但其回复通常缺少显式的情绪识别、支持策略选择和记录摘要。FamleeAI 通过情绪识别 Skill、安全保护 Skill、隐私保护 Skill 与支持策略 Skill 路由，使回复更具情绪贴合度、策略匹配性和长期反思价值。因此，FamleeAI 更适合大学生日常非临床情绪支持场景中的持续陪伴、记录和反思。
